## new design, new back-end and a new blog!

the update that i have been thinking about for a long time is with you now!

as you know, a while ago (about 4 months 😃) i posted an article titled <Link href="/blog/01-new-blog">"new blog!"</Link> and it was pretty exciting. however, from the moment i shared that article, i regretted it. because the blog i shared the article was under another domain name and its design was not compatible with my current site at all. also the backend was very bad and very difficult to manage. on top of that, you see this work that took a long time and you read this article. say hello to my **new blog!**

### technology update on back-end

if you have read my previous post, you must have understood how lazy i am 😃. of course, i didn't bother to write a separate back-end for sharing and managing posts but i'm still lazy. i decided to use [gitHub discussions](https://docs.github.com/en/discussions) instead! thus, my posts will be managed entirely via github and it will be very easy for me to edit them (updating the posts and updating the tags).

another benefit of gitHub discussions is that it made it easier for me to integrate the comment system into posts. since we can comment on discussions, i have added the comment system by showing these comments under my posts. and i did this with an application called [giscuss](https://giscus.app/). giscuss is a comments system powered by gitHub discussions. it lets visitors leave comments and reactions on your website via github!

### front-end update

the blog is now linked to the main site and its design matches the main site. nothing much. 😬
