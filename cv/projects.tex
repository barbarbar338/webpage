    \entry*[2024]%
        \href{https://github.com/dotrocks/sapa-project-electric-stethoscope}{\textbf{Electric Stethoscope}}
        \begin{itemize}
            \item Designed and implemented an electric stethoscope with analog and digital signal processing. A custom casing was designed using SolidWorks and manufactured using a 3D printer.
            \item Used an electret microphone to capture the sound of a heartbeat and amplified/filtered it using an op-amp circuit. A custom Python and Rust based desktop application was developed to filter and visualize the signal.
            \item Implemented the design in real life and acquired the sound of a heartbeat. Filtered signal was seen on a custom-made desktop application.
        \end{itemize}
        \par \url{https://github.com/dotrocks/sapa-project-electric-stethoscope}
